# Orbit Launcher website

This folder contains the public pages required for Roblox OAuth review:

- `index.html` — Entry Link
- `privacy.html` — Privacy Terms URL
- `terms.html` — Terms of Service URL

The repository link is configured for the `AdjectiveYokai` GitHub account.

Once GitHub Pages is enabled for a repository named `orbit-launcher`, the URLs are:

- `https://AdjectiveYokai.github.io/orbit-launcher/`
- `https://AdjectiveYokai.github.io/orbit-launcher/privacy.html`
- `https://AdjectiveYokai.github.io/orbit-launcher/terms.html`
