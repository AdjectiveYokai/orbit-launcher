# Orbit Launcher

Orbit is a customizable Windows launcher for Roblox experiences. It brings discovery, game information, libraries, friend activity, server browsing, and Roblox Player launching into one desktop interface.

> Orbit is currently in active development. A public release will be available soon

## Features

- Join Roblox games seamlessly, Launches in a snap, And go from one game to another in seconds.
- A search engine built right into the launcher.
- Save games as if it were steam to your library.
- A built in friends list, allowing you to join them the same way you would before.
- Customize Orbit's appearance, launch experience, and... pretty much everything soon enough.
- Sign in securely using Roblox OAuth 2.0, or in a browser session for enhanced features.

More is planned before and after release.

## Privacy and account security

Orbit's OAuth login requests only the `openid` and `profile` scopes. OAuth tokens and launcher preferences are stored locally on the user's device, with operating-system protected storage used when available.

Some features require Orbit's optional isolated Roblox browser session. Cookies in that session stay inside a dedicated browser partition on the user's device. Orbit never asks users to paste or reveal a `.ROBLOSECURITY` cookie, this info is also never shared towards a server, your login info is your login info, not ours.
