# Orbit Launcher

Orbit is a customizable Windows launcher for Roblox experiences. It brings discovery, game information, libraries, friend activity, server browsing, and Roblox Player launching into one desktop interface.

> Orbit is currently in active development. No public release is available yet.

## Features

- Search and discover Roblox experiences.
- View live thumbnails, descriptions, ratings, badges, and public servers.
- Save experiences to a local library and track games launched through Orbit.
- See online friends and join available friends through Roblox Player.
- Customize Orbit's appearance and launch experience.
- Sign in securely using Roblox OAuth 2.0 with PKCE.

## Privacy and account security

Orbit's OAuth login requests only the `openid` and `profile` scopes. OAuth tokens and launcher preferences are stored locally on the user's device, with operating-system protected storage used when available.

Some friend features require Orbit's optional isolated Roblox browser session. Cookies in that session stay inside a dedicated browser partition on the user's device. Orbit never asks users to paste or reveal a `.ROBLOSECURITY` cookie.
